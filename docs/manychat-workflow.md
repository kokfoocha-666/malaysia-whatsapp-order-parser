# ManyChat Workflow Example

This project can be used as part of a WhatsApp / ManyChat order-entry workflow:

1. Customer submits order details in WhatsApp
2. Message is copied or sent to parser
3. Parser extracts name, phone, postcode, and address
4. Output is copied into Excel or Google Sheets
5. Seller checks uncertain cases manually

This project does not replace human checking. It is designed to reduce repetitive formatting work and highlight uncertain cases.
